# ADR-0002: 显示口径 - 多窗口剩余百分比（参照 CC Switch）

- 日期：2026-08-27
- 状态：已接受

## 背景
用户明确要求：类似 CC Switch 的显示，不显示剩余 tokens / 调用次数 / 积分，只显示**限制周期内的剩余百分比**。

CC Switch 对智谱显示为：`5小时: 1% 4h37m` / `7天: 20% 1d16h`（多窗口 + 重置倒计时）。

## 决策
- 每张卡片显示**一个或多个用量窗口**，每个窗口：`剩余百分比 + 重置剩余时间`
- 窗口来自各厂商套餐实际限周期（智谱：5小时/周；方舟：5小时/周/月；等）
- 颜色分级：绿（>50%）、黄（20-50%）、红（<20%）
- 悬停/点击可看原始值（数值型余额厂商显示余额金额）

## 后果
- 统一归一化为百分比，跨厂商可对比
- 纯余额型厂商（DeepSeek/Kimi）无"周期限额"，显示为"余额充足度"或余额金额 + 可用状态
