# ADR-0001: 技术栈选型

- 日期：2026-08-27
- 状态：已接受

## 背景
需要一个本地 Web 小应用，展示多家 MaaS 提供商的套餐用量。需要：后端调各家厂商 API、前端展示看板、配置管理、定时刷新。

## 选项
1. **Python FastAPI**：Python 生态适配器好写（requests/httpx），本机已有 Python 3.10+ 环境；F 星简单、自带 swagger
2. Node.js (Express/Fastify)：也是可行选择，但本机 Python 环境更成熟（已有大量 skill 用 python）
3. 纯前端 + 直接调厂商 API：不可行，CORS + API Key 暴露安全问题

## 决策
**采用 Python FastAPI** 作为后端，前端单页 HTML（无构建步骤，原生 JS + 轻量 CSS/图表库），本地存储用 JSON 文件（config.json，后续数据量大了再换 sqlite）。

## 后果
- 优点：开发快、适配器易扩展、与现有环境一致
- 代价：需要维护 Python 依赖（requirements.txt）；FastAPI 启动需 uvicorn
