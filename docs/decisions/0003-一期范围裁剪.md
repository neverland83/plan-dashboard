# ADR-0003: 一期范围裁剪 - 先做已实锤 6 家 + 手动兜底

- 日期：2026-08-27
- 状态：已接受

## 背景
目标厂商 10 家（阿里百炼/火山方舟/腾讯云/百度云/智谱/MiniMax/StepFun/Kimi/DeepSeek...）。
但各家余量查询 API 支持情况差异大：
- 已实锤有公开/社区接口：智谱、Z.ai、MiniMax、DeepSeek、Kimi、火山方舟
- 尚无明确接口：阿里百炼、腾讯云、百度千帆、StepFun

## 决策
**一期只做已实锤 6 家 + 手动录入兜底模式**；探索型厂商二期逐个确认。
手动兜底模式：用户手动填入/更新百分比，保证所有厂商都能上板。

## 后果
- 优点：一期快速可用，框架先跑通，探索型厂商不阻塞主线
- 代价：探索型厂商需要二期开发时逐个核实接口（调研资产已归档，直接复用）
