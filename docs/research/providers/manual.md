# 手动录入兜底模式

> 状态：🟢 一期包含
> 归档日期：2026-08-27

## 目的

对于暂时无法直连查询的厂商（阿里百炼、腾讯云、百度千帆、StepFun 等探索型），提供手动录入的兜底方式，保证**所有厂商都能上板**。

## 行为

- 用户在配置中为该厂商条目选择 `manual` 类型
- 用户手动填写/更新各窗口剩余百分比（或只填一个"总剩余%"）
- 显示时与直连厂商卡片同款样式（带"手动"标记，可加淡色/图标区分）
- 可以设置"上次更新时间"，提醒用户该数据是手动填的

## 未来演进

- 二期探索到某厂商官方 API 后，把该条目从 manual 切换为对应 adapter，无缝升级
- 可加"手动过期提醒"（比如超过 N 天未更新则标灰）

## 配置示例

```json
{
  "id": "tencent-manual",
  "name": "腾讯云（手动）",
  "type": "manual",
  "api_key": "",
  "extra": {
    "windows": [
      { "name": "本月", "percentage": 65 }
    ],
    "note": "控制在台查看后手动填写"
  }
}
```
